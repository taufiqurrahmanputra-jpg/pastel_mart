
# 🛍️ PastelMart

**PastelMart** adalah aplikasi katalog produk berbasis Flutter yang menggunakan DummyJSON API sebagai sumber data. Aplikasi ini memiliki tampilan modern dengan kombinasi warna pastel yang lembut dan nyaman dilihat.

## ✨ Fitur Aplikasi

- Menampilkan daftar produk dari DummyJSON API.
- Menampilkan gambar produk secara online.
- Pencarian produk berdasarkan kata kunci.
- Melihat detail produk.
- Menampilkan harga dan kategori produk.
- Menampilkan rating dan jumlah stok.
- Menampilkan deskripsi produk.

## 🎨 Tampilan Aplikasi

PastelMart menggunakan konsep desain pastel dengan kombinasi warna:
- Lavender
- Soft Pink
- Mint Green
- Baby Blue
- Cream

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| Flutter | Framework pengembangan aplikasi |
| Dart | Bahasa pemrograman |
| Dio | Mengakses REST API |
| Provider | State management |
| GoRouter | Navigasi aplikasi |
| Cached Network Image | Memuat gambar dari internet |
| DummyJSON API | Sumber data produk |

## 🌐 API yang Digunakan

DummyJSON Products API:

https://dummyjson.com/docs/products

Endpoint yang digunakan:
- `/products` — Mengambil daftar produk.
- `/products/search?q=phone` — Mencari produk.
- `/products/{id}` — Mengambil detail produk.

## 🚀 Cara Menjalankan Aplikasi

Pastikan Flutter SDK sudah terpasang.

1. Clone repository:

```bash
git clone URL_REPOSITORY_KAMU
```

2. Masuk ke folder project:

```bash
cd pastel_mart
```

3. Instal dependencies:

```bash
flutter pub get
```

4. Jalankan aplikasi:

```bash
flutter run
```
